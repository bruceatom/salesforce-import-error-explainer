Salesforce Import Error Explainer

Drop the error file from Data Loader, dataloader.io or a Bulk API job. You get the failures grouped by cause, who usually fixes each one, and what to do next. Your file stays in this browser tab. Nothing is uploaded.

How it works

  • It finds the error column (ERROR, sf__Error or similar) and reads the Salesforce status code at the start of each message.
  • It groups rows by code, then by field, picklist value or validation rule message, so one bad value shows up as one fix.
  • Explanations describe the most likely causes. Check them against your org before changing settings.
  • The Import Wizard emails results rather than giving a CSV; you can paste those messages instead.
